# Social Media Location Analytics Dashboard (Power BI)

An interactive Power BI dashboard exploring social media posts and engagement across cities and platforms.

## Dashboard Preview

![Social Media Location Analytics Dashboard](screenshots/dashboard.png)

## Project Objectives

- Analyze social media posts across cities and countries.
- Compare likes, comments, and shares across locations.
- Explore city-level engagement and post counts by platform.
- Use interactive City and Platform slicers to filter the report.

## Dataset

Source file: `Location_Analytics.xlsx`

Fields include `Post ID`, `City`, `Country`, `Platform`, `Likes`, `Comments`, and `Shares`.

## Dashboard Summary

- **Total Posts:** 20
- **Total Likes:** 21K
- **Total Comments:** 2K
- **Total Shares:** 1K

## Key Insights

- Engagement varies between the cities represented in the dataset.
- Mumbai and Bengaluru show relatively high engagement in the project analysis.
- Instagram has the highest number of posts among the platforms shown.
- The map and city-wise charts provide complementary views of location-based engagement.

## How to Use

1. Download this repository or its project files.
2. Open `Powerbi_project.pbix` in Microsoft Power BI Desktop.
3. If prompted, connect the report to `Location_Analytics.xlsx` and refresh the data.
4. Explore the report using the City and Platform slicers.
